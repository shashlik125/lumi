# Lumi — веб-приложение для мониторинга эмоционального состояния

## О проекте

Lumi — это веб-приложение для отслеживания и анализа эмоционального состояния пользователя с функциями дневника настроения, календаря менструального цикла и интеллектуального чат-ассистента «Ася».

## Технологии

- **Frontend:** HTML5, CSS3, JavaScript (ES6), Chart.js
- **Backend:** Python, Flask, Flask-Login, Flask-Bcrypt
- **Database:** PostgreSQL
- **Infrastructure:** Git, GitHub, Railway.app

## Основной функционал

- Регистрация и авторизация пользователей
- Дневник настроения (добавление, редактирование, удаление записей)
- Интерактивный календарь с цветовой индикацией
- Аналитический модуль (графики и диаграммы)
- Календарь менструального цикла
- Фиксация целей и положительных событий
- Чат-ассистент «Ася» с анализом данных
- Экспорт данных в CSV
