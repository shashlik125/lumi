## 1. Общие сведения

Веб-приложение Lumi предназначено для мониторинга и анализа эмоционального состояния пользователя. Реализовано в архитектуре клиент-сервер с доступом через веб-браузер.

Программа обеспечивает:
- Ведение дневника настроения
- Визуализацию эмоциональной динамики
- Аналитическую обработку пользовательских данных
- Эмоциональную поддержку через чат-ассистента

## 2. Функциональное назначение

Основные функции программы:

| Функция | Описание |
|---------|----------|
| Регистрация и аутентификация | Создание учётной записи, вход по email и паролю |
| Дневник настроения | Добавление, редактирование, удаление записей с оценкой 1-10, временем и заметкой |
| Интерактивный календарь | Цветовая индикация дней (зелёный — хорошее настроение, розовый — нейтральное, красный — низкое, серый — нет записей) |
| Аналитический модуль | Круговая, столбчатая и линейная диаграммы, средний балл, количество хороших дней |
| Календарь цикла | Отслеживание менструального цикла и симптомов |
| Цели и радости | Фиксация положительных событий и отслеживание прогресса целей |
| Чат-ассистент «Ася» | Анализ записей, формирование отчётов, ответ на текстовые команды |
| Экспорт данных | Выгрузка данных в формате CSV |

## 3. Описание логической структуры

### 3.1 Архитектура

Программа построена по трёхуровневой архитектуре:

```
┌─────────────────────────────────────────────────────────────┐
│                    КЛИЕНТСКИЙ УРОВЕНЬ                        │
│  HTML5 / CSS3 / JavaScript (ES6) / Chart.js                 │
│  Отображение интерфейса, визуализация графиков               │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼ HTTP/REST API
┌─────────────────────────────────────────────────────────────┐
│                    СЕРВЕРНЫЙ УРОВЕНЬ                         │
│  Python 3.11 / Flask / Flask-Login / Flask-Bcrypt           │
│  Бизнес-логика, обработка запросов, аутентификация          │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼ SQL
┌─────────────────────────────────────────────────────────────┐
│                    УРОВЕНЬ ДАННЫХ                            │
│  PostgreSQL                                                  │
│  Централизованное хранение пользовательских данных           │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 Структура базы данных

Основные сущности и связи:

| Сущность | Назначение | Связь с users |
|----------|------------|---------------|
| users | Учётные записи пользователей | — |
| mood_entries | Записи настроения (оценка, дата, время, заметка) | 1:N |
| hourly_moods | Почасовые записи настроения | 1:N |
| cycle_entries | Дни менструального цикла | 1:N |
| cycle_settings | Настройки цикла пользователя | 1:1 |
| goals | Цели пользователя | 1:N |
| joys | Положительные события | 1:N |

### 3.3 Взаимодействие модулей

```
Браузер (SPA)
     │
     │ HTTP-запрос (GET/POST/PUT/DELETE)
     ▼
Flask Backend (REST API)
     │
     ├──► Модуль аутентификации (Flask-Login)
     ├──► Модуль дневника (CRUD операций)
     ├──► Модуль аналитики (расчёт статистики)
     ├──► Модуль чат-ассистента (обработка текста)
     │
     ▼
PostgreSQL (хранение данных)
```

## 4. Используемые технические средства

### Серверная часть:
- Операционная система: Linux (Ubuntu 22.04) или совместимая
- Среда выполнения: Python 3.11+
- СУБД: PostgreSQL 15+
- Веб-сервер: Flask (режим разработки) / Gunicorn (продуктив)

### Клиентская часть:
- Любой современный браузер:
  - Google Chrome 90+
  - Mozilla Firefox 88+
  - Microsoft Edge 90+
  - Safari 14+
- Подключение к сети Интернет (для доступа к серверу)
- Разрешение экрана: не менее 360×800 (адаптивный дизайн)

## 5. Вызов и загрузка

### Точка входа

Главный файл запуска: `run.py` в корне репозитория.

### Локальный запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/shashlik125/lumi.git

# 2. Перейти в папку проекта
cd lumi

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить приложение
python run.py
```

После запуска сервер доступен по адресу: `http://localhost:5000`

### Деплой (продуктивная среда)

Приложение развёрнуто на платформе Railway.app. Автоматическое обновление при пуше в основную ветку GitHub.

## 6. Входные и выходные данные

### Входные данные

| Тип данных | Формат | Пример |
|------------|--------|--------|
| Регистрационные данные | email, пароль (мин. 8 символов) | user@example.com, password123 |
| Запись настроения | оценка (1-10), дата, время, текст | 8, 2026-06-09, 14:30, «Хороший день» |
| Параметры цикла | день цикла, симптомы, интенсивность | 1, «головная боль», 3 |
| Сообщение чату | текстовая строка | «проанализируй моё настроение» |
| Цель | текст цели | «Кататься на велосипеде» |
| Положительное событие | текст события | «Вкусно поела» |

### Выходные данные

| Тип данных | Формат | Назначение |
|------------|--------|------------|
| Цветовая индикация календаря | CSS-цвет (зелёный/розовый/красный/серый) | Быстрая оценка динамики настроения |
| Графики и диаграммы | Chart.js (canvas) | Визуализация статистики |
| Ответы чат-ассистента | Текст | Анализ и рекомендации |
| CSV-файл экспорта | CSV (разделитель запятая) | Выгрузка записей, целей, радостей |
| Сообщения об ошибках | Текст (всплывающие уведомления) | Информирование о некорректном вводе |

### Формат CSV-экспорта

```
date,time,mood_score,note
2026-06-01,09:30,7,хорошее утро
2026-06-01,18:00,5,устала
2026-06-02,12:00,8,отличный день
```

## 7. Особенности реализации

### Безопасность
- Хеширование паролей с использованием bcrypt (хранение только хеша)
- Управление сессиями через Flask-Login (защищённые cookies)
- Защита от SQL-инъекций (параметризованные запросы через SQLAlchemy)
- Защита от XSS (экранирование пользовательского ввода)
- HTTPS для передачи данных (продуктивная среда)

### Масштабируемость
- Слабая связанность компонентов (трехуровневая архитектура)
- Возможность горизонтального масштабирования (stateless backend + PostgreSQL)
- Поддержка Docker-контейнеризации (планируется)
